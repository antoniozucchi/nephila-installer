# Instalador do Nephila

As versões instaláveis são publicadas em [Releases](https://github.com/antoniozucchi/nephila-installer/releases).

Padrão de publicação:

- Tag: `vA.B.C.D`.
- Instalador anexado: `Nephila A.B.C.D.exe`.

O instalador desta versão atualiza o aplicativo e preserva o banco de dados existente. Antes da conversão do banco, o Nephila cria uma cópia de backup no mesmo diretório.
